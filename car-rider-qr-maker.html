Car Rider QR Card Maker

Generates one printable card per student, grouped by grade, sized for laminating. Student IDs are permanent and stored in a shared registry, so you can run this once per grade and IDs will never collide or reset.
Setup needed: this page still has placeholder Firebase settings, so it can't save permanent IDs yet. Fill in firebaseConfig near the top of the <script type="module"> block with your project's values, then reload this page. Until then, "Save to permanent registry" is disabled and every run is preview-only.
Grade can be K, 1–8, etc. Teacher is optional — leave blank if you don't have it yet. Matching is by first + last name; if two students share an exact name, grade is used to tell them apart.
